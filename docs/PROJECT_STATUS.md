# Project status and provenance

- `src/RC_CAR_recovered.ino` was copied from the recovered `RC CAR.txt` source file and renamed to use the Arduino sketch extension. Its contents were not intentionally modified.
- `images/robot-outdoor.jpg` and `images/robot-front.jpg` are photographs supplied for project documentation.
- `videos/robot-demo.mp4` is the supplied demonstration recording.
- `docs/project-report-summary.md` is a source-based summary of the supplied three-page project report. It omits personal student identifiers.
- No claim is made that the recovered sketch is the exact final version uploaded to the physical robot, or that it was freshly compiled/tested during reconstruction.
